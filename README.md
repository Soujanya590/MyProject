# PESITM ISE Project Hub

A basic student project register for the Information Science & Engineering branch at PESITM, Shivamogga. It runs directly in a modern browser; no package install or build step is required.

## Run

Open `index.html` in a browser. Project records are stored in the browser's local IndexedDB database, `pesitm-ise-project-hub`, in the `projects` object store. Records stay in that browser profile and are not synced to a server or other devices.

## Project records

Each record includes a project title, student team, faculty guide, semester, status, target deadline, and created/updated timestamps. The register supports create, search/filter, edit, and delete.
